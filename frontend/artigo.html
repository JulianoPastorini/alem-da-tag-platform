Como estruturar o Data Layer para CDPs globais

Vinícius Fonseca　·　12 nov, 2026　·　8 min de leitura

Seu Data Layer não precisa falar mil línguas. Precisa de uma estrutura que todos os destinos entendam.

01 / Um contrato, vários destinos

Comece pelo evento, não pela ferramenta. Um schema consistente conecta Adobe, GA4 e seu CDP sem duplicar a lógica de negócio.

dataLayer.js 
window.dataLayer.push({
  event: "lead_generated",
  user: {
    id: "dev_500",
    consent: true
  }
});
{}

{ }   Consentimento faz parte do contrato — valide antes de enviar.
